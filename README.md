

## Build
### option 1 temporary install
~~~ shell
git clone https://github.com/Overionised/silly-particles
cd silly-particles
g++ main.cpp -o silly-particles 
~~~

### option 2 permanent install
~~~ shell
git clone https://github.com/Overionised/silly-particles
cd silly-particles
g++ main.cpp -o silly-particles
sudo cp silly-particles /usr/bin/
~~~
## Run
### option 1 usage
~~~ shell
./silly-particles
~~~

### option 2 usage
~~~ shell
silly-particles
~~~
